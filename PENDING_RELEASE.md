# Pending release (on staging / test, not released yet)

- Map: when Modify structure takes some of the raised centre blocks off a Shelter or Recon Tower, each missing block now shows as a dashed square. The rest stay raised. When all are gone it still looks like a trimmed one.
- Undo after opening a design (or Clear) now brings back the old design's name, Only FOB and haul plan too, not just its pieces. Before, Save could overwrite the wrong design.
- Modify structure: pieces you placed on a roof now fall with it. The warning lists them before you confirm.
- Modify structure: the first click on a structure only picks it. Before, it also added a block there.
- Modify structure: an entrance only closes with the block it takes (Bunker: HESCO Small; Recon, Shelter: HESCO Large or Door). The planner no longer swaps your choice quietly.
- Blocks taken off with Modify structure now add hammer time (7 s each) to the build time.
- A structure can't be placed with its ladder square on a HESCO, Bremer or anything else.
- Showing a threat route closes Side view, like ▶ already did.
- The E key goes back to the piece you were using, like the Erase button.
- Piece list: the "$" column is now called "Supply" (it was always build supplies, not cash).
- Toolbar fits on one row down to about 1280 px wide. New icon for Modify structure.

Rules: no change needed.
