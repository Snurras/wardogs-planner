# Release 10 Oct 2026 (c)

## Changed
- **Modify structure**: the first click on a structure only picks it. Before, it also added a block there.
- **Modify structure**: an entrance only closes with the block it takes (Bunker: HESCO Small; Recon Tower and Shelter: HESCO Large or Door). Pick the wrong one and the planner tells you which to pick, instead of swapping it.
- **Modify structure**: pieces you placed on a roof fall with it. The warning lists them before you confirm.
- Map: when Modify structure takes some of the raised centre blocks off a Shelter or Recon Tower, each missing block shows as a dashed square.
- Blocks taken off with Modify structure add 7 s each to the build time.
- Showing a threat route closes Side view, like ▶ already did.
- The E key goes back to the piece you were using, like the Erase button.
- Piece list: the "$" column is now "Supply" (it was always build supplies).
- Toolbar fits on one row down to about 1280 px wide. New icon for Modify structure.

## Fixed
- Undo after opening a design (or Clear) brings back the old design's name, Only FOB and haul plan, not just its pieces. Before, Save could overwrite the wrong design.
- A structure can no longer be placed with its ladder square on a HESCO, Bremer or anything else.

Rules: no change needed.
